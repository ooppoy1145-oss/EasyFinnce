# EasyFinance - ระบบเว็บไฟแนนซ์ สัญญาเงินกู้และผ่อนชำระสินค้า (Mobile-First & Cloud Sync)

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการสัญญาเงินกู้และผ่อนชำระสินค้า ออกแบบสไตล์ **Mobile-First สำหรับลูกค้า** และ **หน้าจัดการแยกเฉพาะสำหรับพนักงาน/แอดมิน (Admin Portal)** พร้อมรองรับการเชื่อมต่อ **Firebase Firestore Real-time Sync** ข้ามอุปกรณ์ และโมดูลตรวจสอบสลิปธนาคารอัตโนมัติ (**Bank Verification API**) พร้อมนำขึ้นใช้งานบน **GitHub Pages** ได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์หลังบ้านเพิ่มเติม

---

## 🌟 ฟีเจอร์เด่นของระบบ

### 1. หน้าบ้านสำหรับลูกค้า (`index.html` - Mobile-First)
- **หน้า Login ทางการ**:
  - ตัดปุ่มทดสอบ (Demo buttons) ออกทั้งหมด เพื่อความปลอดภัยและความเป็นมืออาชีพ
  - ตัดระบบ LINE Login ออก ลูกค้าล็อกอินด้วย **อีเมลหรือรหัสสัญญา และรหัสผ่าน** ที่แอดมินเป็นผู้กำหนดให้เท่านั้น
  - ระบบบันทึก Session และจำการเข้าสู่ระบบ (Remember Me)
- **Financial Card (การ์ดการเงินพรีเมียม)**:
  - ยอดคงเหลือรวม (Remaining Balance)
  - ระยะเวลาสัญญา (ปี/เดือน/สัปดาห์/วัน)
  - จำนวนสัญญาที่เคยปิดสำเร็จแล้ว (ครั้ง)
  - งวดถัดไปที่ต้องชำระ (วันที่ และยอดเงิน)
  - ป้ายกำกับสิ่งที่กำลังผ่อน (เช่น "ผ่อนทองคำแท่ง 1 บาท", "สินเชื่อเงินสด")
  - ยอดชำระแล้วทั้งหมด (บาท)
  - ปุ่ม **"ชำระเงินตอนนี้ (สแกน QR Code)"**
  - ปุ่มประวัติค่างวด และปุ่มติดต่อเจ้าหน้าที่ (โทร / LINE)
- **หลอดความคืบหน้า (Progress Bar)**:
  - แสดงผล % งวดที่ผ่อนชำระไปแล้ว พร้อมแสงประกาย Shimmer แบบ Real-time
- **หน้าต่างชำระเงิน (Payment Modal)**:
  - **แสดงรูป QR Code รับเงิน**: ดึงรูปภาพ QR PromptPay / บัญชีธนาคาร ที่แอดมินตั้งค่าไว้ออกมาแสดงทันที
  - แสดงชื่อบัญชี, เลขที่บัญชี, ธนาคาร พร้อมปุ่มกดคัดลอกในคลิกเดียว (One-Click Copy)
  - ช่องแนบสลิปการโอนเงิน (Slip Upload) รองรับการลากวาง (Drag & Drop)
- **ตารางรายการงวดทั้งหมด (Installment Schedule)**:
  - งวดที่ชำระแล้ว: แสดงแถบสีเขียว โดดเด่น มีป้ายกำกับ "ชำระแล้ว", "สมบูรณ์", วันเวลาที่ชำระ และรหัสอ้างอิง
  - งวดที่รอชำระ: แสดงยอดเงิน, วันครบกำหนด, ยอดคงเหลือ, สถานะ "-"

### 2. ระบบตรวจสลิปธนาคารอัตโนมัติ (`bank-verification.js`)
- รองรับการต่อ API ตรวจสลิปจริง:
  - **SlipOK API** (`https://slipok.com`)
  - **EasySlip API** (`https://easyslip.com`)
  - **OpenSlipVerify**
- **ระบบป้องกันสลิปซ้ำ (Duplicate Slip Detection)**: ป้องกันไม่ให้ลูกค้านำรูปสลิปเดิมมาอัปโหลดซ้ำ
- **การตรวจสอบความถูกต้อง**: ตรวจสอบยอดเงิน (Amount Match) ว่าตรงกับค่างวดเป๊ะหรือไม่, บัญชีผู้รับเงิน, และเวลาโอน
- **Sandbox Simulation Mode**: มีโหมดจำลองในตัว สามารถทดสอบการสแกนและตัดงวดได้ทันทีโดยไม่ต้องซื้อเครดิต API ล่วงหน้า
- **ตัดงวดอัตโนมัติ**: เมื่อผลการตรวจสลิปถูกต้อง 100% ระบบจะอัปเดตสถานะงวดเป็น "ชำระแล้ว (สมบูรณ์)" ใน Cloud Firestore ทันที

### 3. หน้าจัดการหลังบ้านแอดมิน (`admin.html` - Admin Portal)
- แยก URL ชัดเจน ไม่ปะปนกับหน้าลูกค้า พร้อมระบบรหัสผ่านเข้าหลังบ้าน (Default: `admin1234`)
- **แดชบอร์ดสรุปยอด 4 สถิติสำคัญ**:
  - ยอดปล่อยสินเชื่อรวมทั้งหมด
  - ยอดที่เก็บเงินได้แล้ว
  - ยอดคงค้างรอเรียกเก็บ
  - จำนวนสัญญาทั้งหมด
- **ระบบสรุปและติดตามการชำระเงิน 3 หมวดหมู่**:
  1. **สรุปรายวัน (Daily)**: ลูกค้าที่จ่ายรายวัน — เช็คได้ทันทีว่าวันนี้ใครจ่ายแล้ว (แถบเขียว) หรือยังไม่จ่าย (แถบส้ม) พร้อมปุ่ม "บันทึกรับชำระ" ในคลิกเดียว
  2. **สรุปรายอาทิตย์ (Weekly)**: ลูกค้าที่จ่ายรายสัปดาห์ (ระบุวัน เช่น ทุกวันศุกร์)
  3. **สรุปรายเดือน (Monthly)**: ลูกค้าที่จ่ายรายเดือน (ระบุวันที่ เช่น ทุกวันที่ 1 หรือ 15)
  4. **สัญญาทั้งหมด (All Contracts)**: ตารางรวมสัญญา ค้นหาตามชื่อ, เบอร์โทร, รหัสสัญญา
- **ระบบตั้งค่ารูป QR Code และบัญชีธนาคาร (Payment Settings)**:
  - แอดมินสามารถอัปโหลดรูป QR พร้อมเพย์ / ธนาคารจากเครื่องได้โดยตรง
  - กรอกชื่อธนาคาร, เลขที่บัญชี, ชื่อบัญชี, เบอร์พร้อมเพย์, เบอร์โทรเจ้าหน้าที่ และ LINE ID
  - **ข้อมูลและรูป QR จะซิงค์ไปปรากฏบนหน้าจอชำระเงินของลูกค้าทุกคนทันที**
- **แบบฟอร์มเพิ่ม/แก้ไขสัญญา (Add / Edit Contract)**:
  - มีช่องกำหนด **อีเมลและรหัสผ่าน** ให้ลูกค้า สำหรับนำไปล็อกอินเข้าหน้าบ้าน
  - มีระบบคำนวณและสร้างตารางงวดการผ่อนให้อัตโนมัติตามระยะเวลาและหมวดที่เลือก
- **หน้ารายละเอียดสัญญาและตรวจสอบสลิป (Contract Details)**:
  - เรียกดูตารางงวดทั้งหมดของลูกค้าแต่ละคน
  - กดดูรูปสลิปหลักฐานการโอนเงินที่ลูกค้าอัปโหลดเข้ามา พร้อมรหัสอ้างอิง

## 🚀 วิธีการนำขึ้นใช้งานบน GitHub Pages (Step-by-Step)

ระบบถูกออกแบบให้ทำงานแบบ Client-side และ Cloud-based 100% จึงพร้อมเปิดใช้งานบน GitHub Pages ได้ฟรีทันที:

1. **สร้าง Repository ใหม่บน GitHub**:
   - ไปที่ [github.com/new](https://github.com/new)
   - ตั้งชื่อ Repository เช่น `EasyFinance` แล้วกด **Create repository**
2. **อัปโหลดไฟล์ทั้งหมดขึ้น GitHub**:
   - เปิด Terminal ในโฟลเดอร์โครงการ:
   ```bash
   git init
   git add .
   git commit -m "Initial EasyFinance Release"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO>.git
   git push -u origin main
   ```
3. **เปิดใช้งาน GitHub Pages**:
   - ไปที่หน้า Repository บน GitHub -> เลือกแท็บ **Settings**
   - ในเมนูด้านซ้าย เลือก **Pages**
   - ใต้หัวข้อ **Build and deployment** > **Branch**:
     - เลือก Branch: `main`
     - โฟลเดอร์: `/(root)`
     - กด **Save**
4. **พร้อมใช้งานทันที**:
   - รอ 1-2 นาที GitHub จะแสดง URL สำหรับเข้าใช้งาน เช่น:
     - หน้าบ้านลูกค้า: `https://<YOUR_USERNAME>.github.io/<YOUR_REPO>/`
     - หน้าหลังบ้านแอดมิน: `https://<YOUR_USERNAME>.github.io/<YOUR_REPO>/admin.html`

## ☁️ วิธีเชื่อมต่อ Firebase Firestore (Real-time Cloud Database)

หากต้องการให้ข้อมูลระหว่างแอดมินหลายคนและลูกค้า ซิงค์กันแบบ Real-time ข้ามเครื่องโดยอัตโนมัติ:

1. ไปที่ [Firebase Console](https://console.firebase.google.com/) แล้วสร้างโปรเจกต์ใหม่ (ฟรี 100%)
2. ในแถบเมนูด้านซ้าย เลือก **Firestore Database** แล้วกด **Create Database** (เลือกโหมด Test Mode สำหรับเริ่มต้น)
3. ไปที่ **Project Settings (รูปเฟือง)** > ใต้หัวข้อ **Your apps** กดสร้าง Web App (`</>`)
4. คัดลอกค่าคอนฟิก Firebase เช่น:
   ```javascript
   {
     apiKey: "AIzaSy...",
     authDomain: "your-project.firebaseapp.com",
     projectId: "your-project",
     storageBucket: "your-project.appspot.com"
   }
   ```
5. เข้าหน้า `admin.html` > เมนู **"คลาวด์ Firebase"** > กรอก `Project ID` และ `API Key` แล้วกดบันทึก
6. ระบบจะเริ่มเชื่อมต่อและซิงค์ฐานข้อมูลขึ้น Firestore ทันที

*(หมายเหตุ: หากยังไม่เชื่อมต่อ Firebase ระบบจะจัดเก็บข้อมูลลงใน `LocalStorage` ให้อัตโนมัติ ทำให้เว็บสามารถเปิดใช้งานและทดสอบได้ทันทีโดยไม่มีข้อผิดพลาด)*

## 💳 วิธีตั้งค่ารูป QR Code และบัญชีรับเงิน

1. เข้าสู่ระบบหลังบ้านที่ `admin.html`
2. ที่เมนูด้านซ้าย เลือก **"ตั้งค่า QR รับเงิน"**
3. กดปุ่ม **"อัปโหลดรูป QR Code ใหม่"** แล้วเลือกรูป QR Code พร้อมเพย์ หรือบัญชีธนาคารของร้าน
4. ระบุข้อมูลธนาคาร, เลขที่บัญชี, ชื่อบัญชี, เบอร์พร้อมเพย์, เบอร์โทรเจ้าหน้าที่ และ LINE ID
5. กด **"บันทึกการตั้งค่า"**
6. รูปภาพ QR Code และข้อมูลทั้งหมดจะซิงค์ไปแสดงบนหน้าต่างชำระเงินของลูกค้าทุกคนทันที

## 🛡️ วิธีตั้งค่า API ตรวจสอบสลิปธนาคาร (Bank Verification API)

1. เข้าหน้า `admin.html` > เลือกเมนู **"ระบบตรวจสลิป (Bank API)"**
2. เลือกผู้ให้บริการที่ท่านใช้งาน:
   - **Sandbox Simulation Mode**: (ค่าเริ่มต้น) ตรวจสลิปจำลองเสมือนจริงฟรี ตรวจจับรูปสลิปและยอดเงินอัตโนมัติ
   - **SlipOK API**: กรอก API Key และ Branch ID ที่ได้จาก [slipok.com](https://slipok.com)
   - **EasySlip API**: กรอก API Key ที่ได้จาก [easyslip.com](https://easyslip.com)
3. ติ๊กเลือก **"ตัดงวดในระบบอัตโนมัติเมื่อยอดเงินและบัญชีถูกต้อง 100%"**
4. กดบันทึกการตั้งค่า เมื่อลูกค้าอัปโหลดสลิป ระบบจะทำการส่งไปตรวจและตัดงวดให้อัตโนมัติทันที
