ออฟไลน์

แชร์สต็อครถให้พนักงานทุกคนเข้าถึงและเห็นข้อมูลตรงกันทันที ไม่ว่าจะเปิดจากคอมพิวเตอร์ แท็บเล็ต หรือมือถือ

1. ส่งออกรายงาน (Export)

ส่งออกข้อมูลรถมอเตอร์ไซค์ทั้งหมดเป็นไฟล์ Excel CSV (รองรับภาษาไทย) หรือไฟล์ JSON สำรองฐานข้อมูล

2. นำเข้าข้อมูลสำรอง (Restore JSON)

กู้คืนข้อมูลสต็อคมอเตอร์ไซค์จากไฟล์ JSON ที่เคยดาวน์โหลดไว้

3. รีเซ็ตข้อมูลฟลีทตัวอย่าง (Reset Demo Fleet)

โหลดชุดข้อมูลมอเตอร์ไซค์ Honda ยอดนิยม (Forza, PCX, ADV, Giorno+, NX500, Wave) ทั้งขายและเช่าใหม่อีกครั้ง

📖 วิธีสร้างและตั้งค่า Firebase ฟรี (ทำครั้งเดียวใช้งานได้ตลอด)
1
สร้าง Project ใน Firebase:
เข้าเว็บไซต์ console.firebase.google.com แล้วเข้าสู่ระบบด้วยบัญชี Google -> กด "Create a project" (ตั้งชื่ออะไรก็ได้ เช่น honda-stock)
2
เพิ่ม Web App & รับ Config:
ในหน้า Project Overview กดที่ไอคอนเว็บ </> -> ตั้งชื่อ App -> จะพบโค้ด const firebaseConfig = { ... }; ให้คัดลอกมาวางในช่องด้านบนนี้
3
เปิดใช้งาน Cloud Firestore & Security Rules:
เมนูด้านซ้ายไปที่ Build > Firestore Database -> กด Create database -> เลือก Location (เช่น asia-southeast1)
จากนั้นไปที่แท็บ Rules และวางโค้ดด้านล่างนี้เพื่อให้ทุกคนในร้านอ่าน-เขียนสต็อคได้:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }
กดปุ่ม Publish เป็นอันเสร็จสิ้น!
